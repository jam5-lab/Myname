Hello, I'm a Web Developer

أنا جميلة بدر الروقي، طالبة في مسار Web Development. أطمح أتعلم كيف أبني صفحات ويب تفاعلية وأفهم شلون تشتغل التقنيات خلف الكواليس.

02 · Web in My Words

ببساطة، الويب هو شبكة من الصفحات المترابطة. لما نكتب رابط في المتصفح، المتصفح يرسل "طلب" لكمبيوتر ثاني اسمه الخادم (Server). هذا الخادم يرد علينا بملفات الصفحة (مثل HTML و CSS و JS)، وعقبها المتصفح يترجم هالملفات ويعرضها لنا بشكل صفحة نقدر نقرأها ونتفاعل معها.

03 · HTML · Build the Structure

لغة HTML هي الهيكل الأساسي لأي صفحة، منها نحدد العناوين، الفقرات، والروابط.

<h1>Hello, Web!</h1>
<p>This is my first page.</p>

Hello, Web!

This is my first page.

04 · CSS · Style the Page

لغة CSS مسؤولة عن الألوان والخطوط والتنسيق. جربي تضغطين الزر عشان تشوفين كيف يتغير لون النص فجأة.

h1 {
  color: purple;
}
Hello, Web!

04 · JavaScript · Make it Interactive

لغة JavaScript هي اللي تضيف الحركة والتفاعل. اضغطي الزر وشوفي كيف يتغير النص بدون ما تنعاد الصفحة.

document.querySelector("h1")
  .textContent = "Hello, Web!";

Frontend vs Backend

Frontend

هو كل اللي نراه ونتفاعل معه في المتجر الإلكتروني: المنتجات، الأزرار، وسلة الشراء. هذا الجانب مبني بـ HTML, CSS, JS.

Backend

هو كل اللي يصير خلف الكواليس لما نسجل دخول أو ندفع. ما نشوفه بعيننا لكنه هو اللي يشغل الموقع ويجيب البيانات.
